# Форк Запрета от Кислоты (Saure86)

Удобная сборка утилиты `zapret` для обхода блокировок, настроенная и упакованная Saure86.  
Оригинальная сборка полностью написана **Flowseal** и лишь модернизирована мной. Не призываю скачивать именно мой форк и не гарантирую стопроцентную работоспособность.

## 🚀 Быстрый старт

1. **Скачайте архив:** 
   Нажмите на файл `zapret-saure86-twary1.10.1.zip` на этой странице и нажмите кнопку **Download**.
2. **Распакуйте:**
   Распакуйте архив в удобное место. Крайне желательно, чтобы в пути к папке не было русских букв и пробелов (например, лучше всего закинуть в корень диска — `C:\zapret`).
3. **Запуск и настройка:**
   * Зайдите в распакованную папку.
   * Запустите файл `service.bat` от имени администратора.
   * ⚠️ **ВАЖНО:** Если у вас уже запущен и работает запрет, диагностика работать не будет. Перед тестом убедитесь, что старая служба остановлена.
   * В открывшемся меню выберите пункт **`11. Run Diagnostics`**.
   * Программа сама переберет все доступные стратегии и выдаст самый лучший вариант конкретно под ваш интернет.

## ⚙️ Управление автозапуском (Службой Windows)

Чтобы не запускать программу вручную каждый раз после перезагрузки ПК, её можно установить как системную службу через тот же `service.bat`:

* **Как добавить в автозапуск:** Запустите `service.bat` от имени администратора и выберите пункт **`1. Install Service`** (Установить службу). После этого запрет будет работать сам в фоновом режиме.
* **Как удалить из автозапуска:** Запустите `service.bat` от имени администратора и выберите пункт **`2. Remove Service`** (Удалить службу). Программа полностью сотрет себя из автозагрузки Windows.
